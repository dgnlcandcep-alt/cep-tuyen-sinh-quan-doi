# CEP - Tuyển sinh Quân đội - Render migration starter

Bộ mã nguồn để đưa cổng CEP lên Render với:
- Node/Express Web Service;
- Render PostgreSQL;
- đăng nhập Google/Gmail;
- tên hiển thị tự đặt;
- phòng hỏi đáp chung;
- quyền CEP ẩn/hiện/xóa tin và ẩn/bỏ ẩn học sinh;
- `render.yaml` để tạo Web Service + DB;
- hướng dẫn TENTEN custom domain `quandoi.dgnlqda.vn`.

## Chạy trên Render
Đọc `docs/RENDER_SETUP.md`.

## Quan trọng
Đọc `docs/MIGRATION_STATUS.md`: đây là bộ backend/migration starter, chưa phải export 1:1 toàn bộ frontend tra cứu đang chạy trên ChatGPT Sites.
